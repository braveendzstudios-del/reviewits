== Description ==

**Reviewits – WordPress Testimonial and Review Plugin for Elementor**

Reviewits helps you build customized testimonial pages and display customer reviews on your WordPress website using Elementor.

Create a review layout that matches your website's design and showcase customer feedback with photos and star ratings. Use Elementor's editing interface to customize your testimonial presentation without manually building the entire layout from scratch.

Whether you're building a business website, service website, agency website, or portfolio, Reviewits helps you present customer testimonials in a clear and attractive format.

**Key Features**

* **Custom Testimonial Pages:** Build personalized testimonial page layouts using Elementor.
* **Customer Photo Reviews:** Display customer photos alongside their reviews.
* **Star Ratings:** Showcase customer ratings with star-based review fields.
* **AJAX-Powered Reviews:** Support review submission through AJAX.
* **Elementor Grid Layouts:** Display reviews in grid-based layouts using Elementor.
* **Flexible Design:** Customize your testimonial presentation to complement your website.

**Why Use Reviewits?**

Customer testimonials can help visitors understand other customers' experiences with your business. Reviewits gives you a flexible way to present this feedback using Elementor, allowing you to create a testimonial section that fits your website's design.

== Installation ==

1. Install and activate Elementor.
2. Upload the Reviewits plugin folder to the `/wp-content/plugins/` directory, or install the plugin through your WordPress dashboard if available in the plugin directory.
3. Activate Reviewits from the **Plugins** menu in WordPress.
4. Open Elementor and use the available Reviewits widgets to build your testimonial layout.
5. Configure your review fields and layout according to the options provided by the plugin.
